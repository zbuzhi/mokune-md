# Changelog

## 0.1.0 — unnotarized preview

First public source version of Mokune MD. Previous 0.17.x labels were internal development iterations.

- Source-preserving Markdown editing, independent tabs, themes and workspace navigation.
- Live tables, images, math, Mermaid, footnotes and Front Matter; shared HTML/PDF export rendering.
- Local recovery, session restoration, attachment management and conflict resolution.
- Sparkle 2 signed update integration with document-safe restart handling; updates are enabled after the first archive is published and verified.
- MIT for project-authored code; third-party licenses and source availability documented separately.

Universal DMG and ZIP archives are provided as an explicitly labeled unnotarized preview. See docs/UPDATE-010.md and docs/RELEASE-LEGAL-REVIEW.md for verification scope and remaining release work.
