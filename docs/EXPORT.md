# PDF 与 HTML 导出

在“文件”菜单选择“导出 PDF…”（⌘⇧E）或“导出 HTML…”（⌘⌥⇧E）。导出使用点击时的完整文稿、当前主题、字号和正文宽度；源码模式下也能导出排版后的文稿。

## 输出

HTML 是独立文件：主题 CSS、数学字体、公式排版、Mermaid SVG 与图片全部内嵌，不依赖应用目录、CDN、JavaScript 或联网。普通链接保留为可点击链接；文稿中的安全 HTML 标签与有限内联样式参与排版，脚本和事件等活动内容被清除。

PDF 使用同一份渲染内容生成 A4 页面，保持当前主题，包括深色背景。字号按 CSS 到 PDF 的常规比例转换，正文宽度适配纸张。小表格、公式、图表和图片尽量保持完整；长表逐行分页并重复表头，普通段落按文字行分页。输出保留可选择文字及矢量公式/图表，不是编辑区截图。单个超过一页的内容仍可能跨页；当前不提供自定义纸张或页眉页脚设置。

界面中的预览工具条、编辑按钮、占位边框高度和源码标记不进入导出文件。导出图片保持实际比例，表格完整输出，不受屏幕预览前 100 行的限制。

## 图片与错误

本地图片遵守原有文稿目录范围；未保存的文稿需先保存才能解析相对路径。远程图片须先在预览中点击加载，导出才会重新读取并内嵌；读取不带 Referer 或 Cookie。HEIC 转换为 PNG，便于独立 HTML 查看。

缺失/无法解码的图片、未授权远程图片、无效公式或 Mermaid 会阻止导出，并给出错误，不生成悄悄缺内容的文件。请修复源码后重试。沿用科学预览的片段与安全限制，不执行 Mermaid 文稿内配置或外部资源。

当前上限：100 张图片，单张 20 MB、图片总计 40 MB，PDF 最多 300 页，生成总超时 90 秒。复杂文稿仍可能占用排版线程；更大的文稿可拆分或导出 HTML。

## 原文与输入法

导出只读取快照，不改变 Markdown、保存状态、撤销历史、选区或编辑模式。准备导出期间仍能编辑；导出文件对应点击时的内容，后续输入不纳入这次快照。

候选组合期间不启动导出；如果准备工作在新一轮候选期间结束，等待组合提交后才打开保存面板。取消导出不会保存或丢弃 Markdown 编辑。导出不能覆盖当前 Markdown 文件（包括符号链接指向它的情况）；PDF 先写临时文件，成功后才替换选定的目标。

## 验证

- `pnpm test:export`：独立内容、主题、脚本/网络、源文与选区、错误提示、两轮组合输入保护。
- `tests/pdf/main.swift` 使用与应用相同的 PDFRenderer，验证 A4 分页和全文，含 120 行表格无缺失/重复及重复表头。
- `tests/export-assets/main.swift` 验证图片内嵌、字节一致、目录范围、错误数据与张数限制。
- 样例及截图位于 `output/` 和 `docs/design/implementation/`。PDF 经逐页 PNG 检查。
