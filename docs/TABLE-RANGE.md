# 表格区域选择 · 0.17.2

- 单击单元格继续直接编辑。按住鼠标从一格拖到另一格，选择矩形区域；选中外观使用内侧描边，不改变格子大小。
- 从当前格 Shift 点击另一格扩选，或聚焦单元格后用 Shift＋方向键调整区域；反向拖动也可用。
- ⌘C 复制选区为 Excel / Numbers 可粘贴的 TSV，保留引号、换行与显示文字，去掉 Markdown 格式标记。
- Delete/Backspace 清空所选单元格的内容，保留表格结构、对齐分隔行、空白及未选内容。Esc 取消选区；Enter 回到末端单元格编辑。
- 右键选区内的格子，可复制/清空，或明确选择“删除选区所在 N 行/列”。删除整行、整列影响该行/列的全部内容，与仅清空区域不同。表头行和最后一列受保护。
- 每次区域修改是一笔独立的撤销事务。⌘Z/⌘⇧Z 可撤销/重做；选区聚焦时也可使用。

正在编辑的格子先正常提交，再以新文稿快照建立选区。中文候选输入期间不提交或切换选区，保留输入框草稿。读取模式允许选区复制，清空和删除禁用。结构不齐的表格可清空已有格子；整列删除会拒绝并提示先补齐，避免破坏其他格子。

选区是当前表格的临时交互，不写进 Markdown、HTML/PDF 或会话草稿。切换标签、正文变化、模式切换和预览销毁后失效；在其他段落编辑后复用的表格预览会重新取得当前快照。失效控制器不能修改新文稿。

范围沿用当前即时表格预览的前 100 个正文行；键盘扩选在当前可见预览行列内。暂不提供无限表格、非连续多区域选择、合并单元格、Excel 公式或 xlsx 文件互通。区域粘贴继续通过现有的格内编辑入口，见 [TSV 互通](TABLE-TRANSFER.md)。

验证：6 项模型检查、12 组浏览器交互、2 项新增原生 WebKit 检查（总 20）；覆盖反向框选、键盘扩选、实际复制桥接、未选内容、逐操作撤销、BOM/混合行尾、只读、候选输入草稿、旧快照和表格外编辑后复用。实际导出确认完整表格内容保留、没有选区装饰。指针及候选保护属于自动化检查，不声称新增实体触摸板或输入法候选窗验收。
