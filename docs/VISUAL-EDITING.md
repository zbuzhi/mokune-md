# 表格、图片与导出排版

0.13.0 已调整默认入口与查看器，详见 [编辑交互](EDITING.md)。以下同时保留图片属性与导出设置说明。

0.12.0 原始实现：本轮按顺序完成单元格编辑、图片属性，检查后继续完成导出纸张设置。所有内容操作以局部 Markdown 源码事务提交，原始文件不会因预览或打开面板而被整理。

## 单元格编辑

单击单元格或聚焦后 Enter 为格内输入；悬停铅笔为箭头弹层，右键为行列菜单。源码通过 ⌘/ 编辑，旧工具栏已移除。命令面板保留表格入口。

- 字段支持行内 Markdown。换行写为 `<br>`，新输入的未转义 `|` 写为 `\|`，避免破坏列结构。
- Tab / ⇧Tab 应用当前单元格，进入下一格 / 上一格；首尾边界应用并结束编辑，不自动增加行。
- ⌘Enter 应用并关闭；Esc / 取消保留此次尚未应用的内容之前的源码。此前通过 Tab 已应用的单元格分别保留，可逐次撤销。
- 当前单元格一次应用对应一次 ⌘Z，其他行列的空格、对齐分隔行、BOM、混合行尾及尾随空格保留。
- 空缺列按需补齐，不覆盖现有文本。工具上限为 5,000 行、100 列、单元格 20,000 字符；预览仍显示前 100 行，完整导出全部内容。

标题、正文表格可直接编辑；脚注内的表格通过共享预览/导出渲染，目前在脚注源码中编辑。单元格内容输入支持基础行内 Markdown，尚无所见即所得的加粗工具条或表格合并单元格。

## 图片设置

点击图片下方“图片设置”，或将光标置于图片源码后从命令面板打开。

```markdown
![替代描述](assets/example.png "图片标题"){width=320px height=180px}
![自然比例](assets/example.png){width=50%}
```

宽度可留空、填写 1–8192 px 或 1–100%；高度可留空或填写 1–8192 px，不支持百分比高度。无单位的数字按像素保存。尺寸面板明确区分图片标题和 alt 替代描述；本轮不重写 alt。恢复自然尺寸会移除识别到的尺寸字段。

只设置一个尺寸时另一边按比例适应；同时指定宽高时完整放入尺寸区域，使用 contain 避免拉伸。小窗口与纸张仍限制最大宽度/高度，实际输出不会超出可用页面。标题使用标准 Markdown title；独立图片显示题注，嵌在文字或表格中的图片保留悬停标题。

修改引用式图片的尺寸只作用于当前出现位置；修改其共享标题时，仅将这一处转为包含相同路径的行内图片，原定义和其他引用不变。非法或未知属性块保持字面文本，不注入任意 CSS；应用时仅修改识别到的属性或增加明确的新尺寸属性。引用路径继续沿用原生范围校验，远程图片仍须主动加载。

## 输入和未应用内容

编辑面板用独立 textarea/input 接收中文候选；候选期间 Enter、Esc、Tab、应用/取消按钮不会提前提交或移走焦点。60 ms 延后释放并检查代次，不会由旧 compositionend 解锁新组合。应用前再次核对当前 EditorView、doc 身份及只读状态，正文有变化时保留输入并提示复制/取消。

面板未完成时暂停自动保存调度、阻止切换模式/导出/关闭标签/退出；原生新文稿和文件打开同样受保护，Finder 打开请求等待面板结束。字段本身的未应用内容暂不写入崩溃恢复档案；文稿已有草稿机制保持不变。只读模式禁用修改控件。

## 导出排版

`⌘,` 打开“编辑设置”，在“导出排版”选择 A4 / US Letter、纵向 / 横向、10 / 14 / 20 / 25 mm 页边距。默认 A4 纵向、14 mm。主题、字体和正文宽度继续沿用当前设置。选择只影响后续导出，不修改源文、光标或撤销历史。

独立 HTML 含相同 `@page` 打印规则和原生 PDF 所用的枚举页面元数据；浏览器最终打印结果仍可能受浏览器打印对话框选项影响。原生 PDF 每次任务重新计算纸张和可用页高，图片/题注尽量保持在一起，长表继续分页并重复表头。

## 检查

新增 8 项逻辑测试与 13 类浏览器场景。覆盖修改/取消/一次撤销、Tab 导航、中文组合事件、引用图片隔离、尺寸拒绝、原文字节、只读和多标签。Mac 窗口实测单元格应用/撤销、待应用阻止退出、图片标题/百分比宽度应用与撤销；自动化未被表述为实体键盘系统输入法验收。原生 A4 与 Letter 横向 PDF 已检查，另回归明暗主题与 120 行长表。结果见 VISUAL-TEST-RESULTS.json、VISUAL-PDF-RESULTS.json、VISUAL-LETTER-PDF-RESULTS.json。

补充检查：异步图片导入等到面板结束；先前导出的完成通知不会在候选期间把焦点拉回正文。主题切换与文稿查询结果同样延后处理。
