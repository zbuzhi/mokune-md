# 架构

Mokune MD 使用 Swift / AppKit 提供原生窗口、菜单、文件操作和系统集成，系统 WKWebView 承载本地 CodeMirror 6 编辑器。应用不包含 Electron、额外 Chromium 运行时、Java 运行环境或 WASM。

## 源文与编辑状态

CodeMirror 文档是编辑的唯一真源。预览 HTML 和 AST 不会反向序列化覆盖 Markdown。独立元数据保存 BOM、混合行尾和尾随空格，局部编辑与撤销同步更新，未修改内容按原字节保存。

每个标签独立保留编辑状态、撤销历史、选区和滚动位置。重启恢复源文、标签与阅读位置，撤销历史仅限当前进程。中文组合输入期间冻结会干扰输入的预览重建、自动保存和格式操作。

## 渲染

即时排版通过 CodeMirror decoration 与块级 widget 实现。共享 Markdown 解析、主题 token、KaTeX、Mermaid 和安全 HTML 规则支撑即时预览及 HTML/PDF 导出；导出读取完整文稿快照，不依赖虚拟视口，也不修改源文。

科学预览独立按需加载；缓存只保存渲染结果。异步结果在应用前检查 widget 是否存活、输入是否仍在组合。KaTeX 字体内嵌，Mermaid 输出经过 DOMPurify 清理。ELK 由 Mermaid 引入，实际运行的是 JavaScript，独立保留 EPL-2.0。

## 文件和安全边界

原生桥只接受应用本地页面的受控消息，不提供任意命令执行接口。写入前比对磁盘快照，冲突保留当前草稿；逐段合并可撤销。文件树、资源操作和链接维护同时检查相关标签的未保存内容。

本地图片通过受授权根目录约束的自定义 URL scheme 读取，检查真实路径、符号链接、类型和大小。远程图片由用户明确加载。文稿不能执行脚本，编辑器代码和字体不从 CDN 下载。

## 更新与发行

Sparkle 2 提供签名更新，公开 HTTPS feed 与公钥随应用配置，私钥不在源码/应用中。安装重启等待编辑器同步和未保存确认，原子写入会话后才允许退出；输入、取消或写入失败会拒绝终止。见 [更新验证](UPDATE-010.md)。

构建支持宿主架构或 arm64/x86_64 通用 App。默认图标使用已选定的 MD7 原稿，完整 Xcode 编译现代图标目录，静态 ICNS 兼容构建可选。正式签名、公证、第三方源码及升级检查与源码公开分开处理。见 [构建](BUILDING.md)、[发布](RELEASING.md)。
