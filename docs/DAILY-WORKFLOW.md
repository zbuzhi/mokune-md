# 0.9.0 日常编辑补全

## 版本历史与冲突

“文件 → 版本历史”或命令面板搜索。修改已有文稿并保存前，先保留磁盘基线内容；重复内容不重复留档。版本以文稿路径隔离，最多 30 版/40 MB，总计 200 MB，超限清理最旧记录。打开新文稿尚未修改保存时可能没有历史。草稿恢复、编辑撤销、历史快照分别负责崩溃恢复、当前编辑会话撤销和已保存旧版回看。

预览左右展示当前编辑与选定版本，突出不同区段。比较最多展示前 2,000 行/200,000 字符，恢复仍使用完整原文。恢复到编辑器是一笔可撤销事务，启用自动保存时也会按设置保存，因此恢复前的当前磁盘内容仍会留档。历史包含源文，不包含图片资源副本；按路径区分，改名或移动后旧历史不会自动出现在新路径。

外部冲突可点“比较版本”查看当前编辑与磁盘。比较不修改源文，不解除冲突、不自动合并；关闭后仍使用“另存我的版本”或确认“载入磁盘版本”。仅 BOM/行尾不同也会明确提示。

## 图片

已有导入对话框之外，可直接粘贴剪贴板图片，或将图片拖到正文。每批最多 10 张、总计 20 MB，复制到当前文稿旁边的 assets，重名自动递增。要求先保存文稿。普通文字粘贴仍由编辑器处理。

批量图片作为一次可撤销的 Markdown 插入。读取或复制期间发生编辑、切换文稿或进入只读模式时不覆盖现有编辑；候选期间延迟插入。图片写入后不会因撤销文本而删除资源，避免损坏其他引用。粘贴文件传输使用 WebKit clipboardData 的图像文件；部分软件只提供图片 HTML/URL 时不会自动下载网络资源。

## 表格

点预览中的“表格工具”，或将光标放在表格内从命令面板打开。支持在当前行下插入一行、右侧增加一列、光标所在列左对齐/居中/右对齐。点击预览工具条时默认以表头首列为操作位置。每次修改只编辑表格相关区间，可一次撤销。追加列要求每行列数一致；工具支持 5,000 行/100 列以内，更大的表格保留源码编辑。

## 链接与位置

按住 ⌘ 点击 Markdown 链接，或光标位于链接时按 ⌘⌥Enter。支持行内/引用式链接、中文路径及标题锚点；重复标题使用 `-1`、`-2` 后缀。相对链接可在已打开工作区内跳转，没有工作区时限定文稿所在目录。跨文稿打开仍经过未保存提示。HTTP(S)/mailto 使用系统默认程序；其他协议不执行。

左上角返回/前进及 ⌘⌥←/→ 返回链接跳转前的文稿和行列，历史最多 100 项。它是当前会话的链接导航，不是多标签；重新加载文稿仍遵循单文稿编辑器的历史生命周期。

⌘, 打开编辑设置。位置记忆为最近 100 份有路径文稿保存光标行列与滚动位置，可关闭；更改文稿长度后会将光标限制在有效范围。折行只改变显示，缩进设置影响后续操作，不批量改写已有内容。打字机滚动在提交输入后居中当前行，中文候选期间不滚动。
