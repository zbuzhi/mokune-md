# 脚注与文稿信息

0.11.0：即时预览、独立 HTML 与原生 A4 PDF 使用同一份扩展解析和主题样式，源文件始终以原始 Markdown 保存。

## Front Matter

仅识别文稿第一行的 `---`，以独立一行 `---` 或 `...` 结束；前面有空行的分隔线仍按普通 Markdown 处理。

```yaml
---
title: 代码与文字之间
author: Mokune
tags: [Rust, macOS]
description: |
  第一行简介。
  第二行简介。
---
```

预览和导出都显示文稿信息卡，不拿 title 替换正文标题，也不隐藏任何字段。支持映射、序列和多行字符串，嵌套值紧凑显示；点击“编辑信息”回到 YAML。格式错误、重复键、未知标签、非键值结构、过量别名或超过 64 KB 时，显示提示及完整转义源码；不执行自定义标签，不整理字段、引号、注释或缩进。尚未闭合的分隔块保持普通 Markdown。原文件的 BOM、原始行尾、空白不受影响。

## 命名脚注

```markdown
正文说明[^design]，还可以再次引用[^design]。

[^design]: 支持 **强调**、链接与 $E=mc^2$。

    缩进四个空格，可以继续第二段、表格、图片和代码围栏。
```

标签区分大小写，不含空格。按首次引用的次序编号，重复引用仍显示相同编号，返回链接分别回到各次引用。点击正文编号或文末“编辑”返回定义源码；当前定义正在编辑时显示原文，其他已引用定义收起，完整预览集中在文末。HTML/PDF 同样采用文末脚注，不排成逐页页脚。HTML 保留锚点，PDF 通过现有渲染器输出文稿内容，未保证 PDF 内部跳转链接。

脚注内使用既有公式、Mermaid、表格及图片规则。远程图片须主动点击加载后才能导出；未保存文稿的相对图片要求先保存。未引用定义不进入导出的脚注列表，缺失定义的引用、代码块内的写法和转义引用保持字面文本。暂不启用非标准 `^[行内脚注]`；源码仍完整保留。大纲排除文稿信息和脚注定义内部标题。

## 快捷键

- `⌘/`：源码与即时预览切换，兼容 `⌘⇧M`。
- `⌘⌥N`：插入唯一脚注标签，将选中文字作为脚注内容；未选择时提供内容占位。
- `⌘⌥.`：插入分隔线。

加粗、斜体、代码、引用、标题和列表等完整列表见 SHORTCUTS.md，原生“格式”菜单和命令面板均可发现。格式操作可一次撤销，候选输入时暂停执行；模式切换不产生源文更改。

## 验收

5 项新增逻辑测试、12 类专项浏览器场景、既有预览/导出/多标签/导航等回归；`tests/fixtures/extensions.md` 为可直接打开的示例。Mac WebKit 实测显示卡片、脚注内图表/公式/图片/表格以及 ⌘/ 双向切换；原生 PDF 生成两页，已逐页检查。自动组合事件覆盖冻结、格式拦截和撤销，没有新增实体键盘系统拼音/双拼结论。
