# 文件树与悬浮大纲

左侧管理本地文件，正文页边管理本篇标题。

## 文件与文件夹

用 ⌘⇧O 选择文件夹；文件夹箭头、缩进与连接线标明层级，当前文稿自动展开定位。明确选择的根目录在下次启动恢复。

文件夹标题旁的两个小按钮分别新建文稿、文件夹。先选中父目录，再点按钮；也可右键任意项目，或点移入时出现的 ⋯。名称直接在目录树内填写，Enter/✓ 确认，Esc/× 取消。新文稿使用 .md、.markdown 或 .txt 扩展名。

右键菜单或 F2 重命名。拖动文件或文件夹到目标文件夹，目标高亮后松手即可移动；移动完成后展开目标目录并定位项目。拖到文件所在行会移入该文件的父目录。禁止根目录重命名/移动、同名覆盖，以及把文件夹移入自己的子目录。此版本不提供删除、跨根目录移动或从 Finder 拖入导入。

↑↓ 定位，→ 展开/进入，← 收起/回父级，Home/End 首尾，Enter/空格打开。根目录按需读取并自然排序，隐藏文件、符号链接、应用包与 node_modules 不显示；每层最多 1,000 项并提示截断。

## 自动刷新与未保存保护

使用 macOS FSEvents 监听根目录和子目录变化，合并事件后刷新当前展开的目录。保留展开状态和侧栏滚动；命名、拖拽或中文组合输入期间延后刷新，完成后显示变化。

重命名或移动当前文稿、包含当前文稿的文件夹时，只更新磁盘位置、窗口名称与本地图片目录，不重新载入正文；选区、撤销历史、原始行尾和未保存编辑保持。移动前若发现磁盘版本与打开时不同，会阻止操作并提示先处理冲突。同名项目不会覆盖。

新建文件后会尝试打开；当前文稿有未保存更改时，沿用“保存/取消/不保存”保护。取消切换仍保留刚创建的空文件。⌘N 与底部“新建文稿”仍是建立未保存编辑缓冲区，保存时再选择位置。

外部修改、重命名或删除当前文稿不会静默替换正文，会显示冲突提示并停用自动保存，可另存副本或明确载入磁盘版本。外部重命名当前文稿暂不自动跟踪新路径。移动单个 Markdown 文件不重写图片路径；移动整份文件夹时目录内相对关系保留。

## 页边大纲

默认位于正文右侧，平时以超小标题逐行显示；窄窗口收成短线。移入扩大后的页边感应区，约 45ms 后淡入完整标题；移出保留约 210ms 余量。取消缩放弹出，改用轻微侧移与柔和淡入；减淡边框、阴影及标题栏，避免厚重弹框感。浮层不挤压正文，也不改变编辑焦点。

点击标题跳转，当前章节高亮；图钉固定，关闭或 Esc 收起。“外观与主题 → 悬浮大纲”可选择左侧、右侧、隐藏并记住偏好。“显示 → 展开本篇大纲”也可唤出。无标题文稿不显示空卡片，代码、HTML、独立公式中的井号不计入标题。系统“减少动态效果”开启时禁用过渡。
