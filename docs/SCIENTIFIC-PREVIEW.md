# 公式与 Mermaid 预览

公式使用本地打包的 KaTeX；图表使用本地打包的 Mermaid。渲染器按需加载，不依赖 CDN。公式字体也随应用打包。

## 支持的写法

- 行内公式：`$E=mc^2$` 或 `\(E=mc^2\)`。
- 独立公式：单独一行的 `$$…$$`，或以单独的 `$$` / `\[` 开始、`$$` / `\]` 结束的多行公式。
- 公式代码围栏：语言标记 `math`、`latex` 或 `tex`。
- Mermaid：语言标记 `mermaid` 的完整代码围栏，例如流程图、时序图、类图等 Mermaid 支持的图表。
- 公式使用 KaTeX 支持的 TeX 子集；不是完整 LaTeX 编译器。普通价格、转义美元符号和普通代码中的美元符号保留原状。首版不解析表格单元格、链接及 HTML 内的公式。

点击行内公式、或点击块预览的“编辑源码”，返回对应原文。编辑中的块保留源码并在下面显示预览。格式错误时显示就地提示；未闭合代码围栏保持源码。大图表在固定预览框中显示，避免异步生成结果挤动正文。

## 中文输入与文件保存

预览是 CodeMirror 的装饰，不是另一个文档。没有从 HTML 或 SVG 回写 Markdown 的步骤。

候选组合期间保留现有预览 DOM，只映射源码位置；异步完成的公式或图表结果也等待组合结束后再显示。编辑延迟 180 ms 后生成预览，相同内容复用有限缓存。主题更换仅重新生成图表颜色，不改写文稿。

BOM、原始行尾、尾随空格与未知语法仍通过原有源文状态保存。预览加载失败、语法错误、模式切换和主题切换不会触发格式化或文稿序列化。

## 渲染边界

KaTeX 使用 `trust:false`、有限宏展开、有限尺寸，宏不跨公式共享。Mermaid 使用 strict 安全模式、文本标签和 SVG 清理，禁用文稿内配置指令、HTML 标签、链接交互与外部资源。图表文字与提示不注入可执行 HTML。含 URL、图片或外部资源的图表片段在渲染前拒绝（包括作为普通标签文字的 URL），避免 Mermaid 临时测量 SVG 发出请求。外部链接请放在正文里。

单段公式超过 8,000 字符、单段图表超过 20,000 字符时暂停预览；Mermaid 边数上限为 300。源码始终保留可编辑。这些是首版交互上限，不是性能承诺；特别复杂的片段仍可能暂占渲染线程。
