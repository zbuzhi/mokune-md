# 图片与附件管理 · 0.15.0

## 入口与图片编辑

“文件 → 图片与附件…”打开资源管理，也可从 ⌘⇧P 命令面板搜索。界面采用资源列表与预览／引用位置两栏，支持文件名和路径搜索，以及“全部资源 / 失效引用 / 可清理资源”筛选。

图片继续保持正文内无边框显示。右键图片打开“图片设置”：

- 替代文字与图片标题独立编辑。替代文字用于无障碍和图片无法显示时的描述，标题沿用原有题注规则。
- “替换图片…”把所选图片复制到文稿旁的 `assets`，重名自动递增。点击“应用”后才更新当前图片路径，保留替代文字、标题、尺寸和对齐。
- “定位原文件”在 Finder 中显示当前图片链接指向的本地资源；远程图片或失效路径会明确提示。

替代文字、路径、标题和尺寸可一起应用为一次撤销事务，只修改相应 Markdown 范围。引用式图片需要修改替代文字、路径或标题时，仅将当前这一处转为行内写法，不改共享引用定义。未修改的转义写法、未知属性、BOM、原始行尾及其他源文保持不变。预览与 HTML/PDF 仍共用同一套解析规则。

替换不会覆盖或删除原图片。取消设置后已复制的新文件仍保留，可在资源管理中检查；撤销修改也不删除磁盘资源，避免损坏其他引用。

## 附件

“文件 → 插入附件…”复制普通文件到当前文稿的 `assets` 并插入相对 Markdown 链接，单份最多 20 MB，支持重名递增。源文件保持不变；插入可一次撤销。要求先保存文稿。

⌘ 点击本地附件链接时，PDF、图片及常见媒体、Office 文档使用系统默认应用打开；其他格式在 Finder 中定位。相对目标仍须位于当前所选工作区内，没有对应工作区时限于文稿目录。不会把 `.command`、脚本或未知附件作为程序执行。

资源管理可查看工作区中的常见图片／附件，以及 `assets` 内的其他文件。图片显示本地预览，其他附件显示类型、大小、路径及引用位置；不将类型图标描述为 PDF／Office 内容预览。引用位置可跳回相应标签和行，保留后台草稿。

## 引用与保护范围

检查覆盖工作区磁盘文本、所有已打开文稿的未保存内容，以及当前各标签的撤销／重做历史。磁盘原文与草稿不同会分别检查，避免草稿移除引用后误清理磁盘版本仍需的资源。

支持 Markdown 图片、文稿／附件链接、引用式定义及常见 HTML `href` / `src` / `poster` / `data`。代码、公式和 Front Matter 不作为普通失效链接报告，但出现资源文件名的可疑文字提及会保守保留资源。远程地址不主动联网检查。macOS 路径按所在卷的大小写规则及 Unicode 规范化比较。

资源不会因单次没有明确引用就自动移除。`assets` 之外的文件、已在标签中打开的文件、未知清理类型，以及存在明确／可能引用的文件只供查看。

## 清理与还原

1. 选择“可清理资源”，逐项勾选，或勾选“选择当前列表中可清理的资源”。默认不选中任何文件。
2. 右侧查看图片或附件信息及路径，再点击“移入废纸篓…”。
3. 原生确认框列出所选项目。确认后重新核对文稿、草稿和资源状态，再移入系统废纸篓。

清理只允许处理 `assets` 下已完整检查的常见资源格式，不执行永久删除，不修改文稿。面板提供“撤销清理”，支持还原当前运行期间最近一批；重启后仍可通过 Finder 废纸篓恢复。原位置冲突或父目录改变时拒绝覆盖。

预览期间发生外部文件变化、文稿编辑、标签集合变化或资源替换时，旧清理计划失效，要求重新检查。批量移入废纸篓若中途失败，已移走的部分仍保留还原记录并明确提示，不冒充整批成功。

扫描不完整、权限不可读、遇到未扫描的包／符号链接，或撤销历史超出保护检查预算时，清理停用。扫描上限为 20,000 个项目、2,000 个资源、40 MB 实际文本／未知格式读取；已知二进制文件只读取元信息。撤销／重做检查限 200 步、约 8 MB 文本。扫描在后台执行，关闭面板会取消。列表每次最多显示 300 个匹配项，可用搜索进一步定位。

扫描不覆盖其他工作区、网络内容、构造式动态路径或独立的旧版本历史图片副本；清理确认前应按路径核对待清理资源。版本历史仍只保存 Markdown 源文，不备份图片。

## 输入与撤销

资源管理打开前同步当前草稿；面板期间暂停正文编辑、自动保存与文稿切换。搜索框中文组合输入时禁止清理和关闭；图片字段组合输入时禁止应用和替换。文件选择完成后校验文稿与选区，发生编辑或切换时保留复制的资源，不覆盖新输入。

查看引用、显示原文件、扫描及清理不重建正文编辑器，不消费实际撤销栈。历史引用检查只遍历独立不可变状态，不对当前文稿发出撤销操作。

## 验证

- `tests/resources.test.mjs`：引用解析、路径、可疑引用、撤销／重做只读检查及 Mac 大小写／Unicode 场景。
- `tests/visual-model.test.mjs`：替代文字、替换、共享引用隔离及预览／导出解析一致性。
- `tests/resources-browser.mjs`：图片联合编辑和撤销、历史图片保护、失效引用、明确选择与取消、候选期禁止清理及不完整扫描保护。
- `scripts/test-resources-native.sh`：临时目录扫描、磁盘／草稿双重保护、过期预览、附件复制、扫描取消、assets 外只读及符号链接保护。
- `scripts/test-resources-app.sh`：生产 AppDelegate 与 WebKit 桥接；真实文件复制、原生图片预览、真实 macOS 废纸篓移入及字节一致还原、过期引用拒绝、后台草稿、图片／附件撤销。所有文稿均在独立临时目录；文件选择与确认在测试副本中替换，Finder 激活替换为检查已验证的目标 URL。截图见 `output/resources-native.png`。

中文输入检查使用程序化组合事件与中文插入，不将其描述为重新完成实体键盘候选验收。没有重启用户正在使用的应用。

本轮会话回归还补充后台阅读位置恢复：动画帧停用时进行有界的定时恢复，避开后续滚动锚定；点击、滚轮、键盘或中文输入开始时取消延迟恢复，不覆盖用户操作。主动停用动画帧的浏览器用例与原生重启回归通过。
