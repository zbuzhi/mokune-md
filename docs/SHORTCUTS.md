# Mac 快捷键

⌘ Command，⇧ Shift，⌥ Option。格式操作可以通过“格式”菜单发现，候选输入期间暂停执行。

单独按住 ⌘ 0.5 秒，底部显示常用快捷键速查，松手收起。使用组合快捷键、点击或切换窗口会取消提示；中文候选和编辑弹窗期间不弹出。浮层不获取焦点，不改变源码、光标或撤销历史，跟随当前主题并支持减少动态效果。

图片快捷键插入 Markdown 路径占位，填写后预览；它不会上传图片。多数格式快捷键再次执行可移除已有格式。每次格式变更可一次撤销，原始行尾元数据随撤销恢复。

文件树支持 ↑↓、←→、Home/End 定位与展开，Enter/空格打开文稿。大纲可从“显示 → 展开本篇大纲”打开；悬停展开后点击标题跳转，图钉固定，Esc 收起。“外观与主题”可选择大纲位于左侧、右侧或隐藏。

目录项获得焦点后按 F2 重命名；名称框 Enter 确认、Esc 取消，中文候选期间不提交命名。目录新建与移动也可从右键或 ⋯ 菜单发现，拖放目标会高亮。

文稿统计可点击底部字数，或通过“显示 → 文稿与选区统计”打开；也可在命令面板搜索。自动保存开关位于编辑设置，关闭后 ⌘S 手动保存，恢复草稿仍会保留。本地图片导入要求先保存文稿，将图片复制到旁边的 assets 目录，重名自动递增。

“文件 → 版本历史”可预览和恢复旧版；恢复按钮支持 ⌥Enter，恢复后可 ⌘Z 撤销。冲突提示的“比较版本”仅展示差异。表格预览工具条可打开行列与对齐工具，也可从命令面板搜索“表格工具”。

脚注快捷键生成不重复的数字标签，在当前位置插入引用并在文末添加定义，选中脚注内容以便输入；一次撤销恢复整次插入。源码切换只改变显示，不改原文或撤销历史。

表格单元格单击或聚焦后 Enter 打开编辑面板，⌥点击定位对应源码。面板中 Tab/⇧Tab 应用当前单元格后前后切换，⌘Enter 应用并关闭，Esc 取消当前未应用内容；之前用 Tab 已提交的单元格可分别 ⌘Z 撤销。图片“设置”同样使用 ⌘Enter 应用、Esc 取消，中文候选期间不响应这些提交/取消键。

“编辑设置 → 导出排版”可选择 A4/Letter、横向/纵向和 10/14/20/25 mm 页边距；HTML 携带相同打印样式。导出快捷键不变。

0.13.0：表格格内 Enter 提交、Shift+Enter 换行、Tab/⇧Tab 逐格提交、Esc 取消当前输入；铅笔弹层仍支持 ⌘Enter。图片/图表查看器中 ←/→ 切图，＋/− 缩放，Esc 关闭，双击复位；触摸板支持捏合与平移。

0.13.1：单击链接或移入光标即可原位编辑，⌘点击打开。图片右键进入设置；边缘与角拖动调整尺寸，Shift 拖动分别设置宽高范围。

0.13.3：图片拖动调整尺寸时按 Esc 取消，恢复拖动前尺寸并继续正文编辑。
