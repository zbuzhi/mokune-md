# 多标签与文件整理 · 0.10.0

## 文稿独立状态

打开、新建、文件树打开和链接导航使用标签；再次打开相同规范路径会定位已有标签，保留尚未保存的编辑。一次最多 30 份文稿。未命名文稿按序编号，标题旁圆点表示未保存。

切换时保存完整 CodeMirror EditorState，再重建当前可见视图。因此正文、原始行尾/BOM、撤销/重做栈、选区、滚动位置、源码/只读模式及冲突状态各自独立；后台标签不保留可见 DOM。主题与编辑偏好仍是全局设置，切回时更新显示。当前会话的撤销栈保留到标签关闭，重启后的恢复草稿恢复正文，不承诺恢复此前的撤销栈。

⌘W 关闭当前标签；⌘⇧[ / ⌘⇧] 切换标签，也可用标签上的 ×。候选组合输入期间不切换或关闭。关闭未保存标签可保存、取消或不保存；退出应用会逐份处理所有未保存文稿，不只检查当前标签。保存/文件选择面板期间到达的外部打开请求排队处理。

保存请求携带文稿 ID，旧回执不会写入另一标签的状态。另存目标若已在其他标签打开，明确拒绝覆盖。打开的目录或文件改名时会检查并更新所有相关标签。后台文稿的磁盘变化在激活时核对，保留编辑并显示冲突；不会自动覆盖或重载正文。

恢复档案为每份未保存文稿存储原始 UTF-8 字节（Base64）、路径及磁盘基线，兼容旧的单文稿档案。保存或放弃某一份，不清除其他未保存文稿。切换时立即同步草稿；正常编辑仍按短延迟写入，因此崩溃前尚未写入的最新输入仍可能丢失。后台草稿切回后按自动保存设置继续处理。

## 文件整理

文件树的 ⋯ 或右键菜单支持“在 Finder 中显示”和“移入废纸篓”；焦点位于目录项时 ⌘⌫ 可发起移除，正文中的删除快捷键不受影响。工作区根目录不能移入废纸篓。

移除前检查该文件/目录内所有已打开文稿。任何一份未保存或存在磁盘基线冲突，均拒绝操作，要求先保存、另存或处理冲突。确认后使用系统废纸篓，关闭相关已保存标签；不会调用永久删除来移除用户文稿。

状态栏提供一次“撤销”，将最近移除的项目还原到原位置。同名冲突、父目录不可用或边界变化时拒绝覆盖，项目仍可在 Finder 废纸篓中恢复。应用内撤销记录仅保留当前运行期间最近一次操作；退出后仍可通过系统废纸篓恢复。

“文件 → 在 Finder 中显示”以及命令面板也可定位当前已保存文稿。
