# 表格与 Excel / Numbers 文本互通

0.17.0，2026-10-26。

## 粘贴区域

1. 在 Excel / Numbers 等表格软件复制一片单元格。
2. 点击 Mokune MD 的目标表格单元格，进入格内编辑。
3. 粘贴。制表符文本按行列写入，以当前单元格为左上角；需要时自动补行、补列。标题行粘贴会跨过 Markdown 的分隔行，不会用数据覆盖对齐语法。
4. 一次 ⌘Z 撤销整个区域粘贴，⌘⇧Z 重做。其他文稿和已有撤销历史独立保留。

铅笔打开的单元格弹层也接受同样的区域粘贴。带制表符的数据识别为多列；单列多行使用剪贴板的表格类型/HTML table 标识判断。普通不带表格标识的多行文字继续按一个单元格内容处理，不擅自拆成多行记录。

支持 CRLF/LF、带引号的制表符和换行、双引号转义、空单元格及 Excel 尾部换行。竖线写入为 `\|`，格内换行写入为 `<br>`，保留已有的 Markdown 行内写法。

如果当前输入框已经有未提交内容，先按 Enter 应用或 Esc 取消；区域粘贴不会静默丢掉这份字段草稿。候选输入期间阻止区域提交，错误的引号或越界范围保持源文与输入框不变。

## 复制整表

右键任一单元格 → **复制表格到 Excel / Numbers**。输出为显示文本 TSV，去掉 Markdown 粗体/代码分隔符，保留实际文字、换行、引号和竖线。读取模式也可复制；修改类菜单保持禁用。

Mac 通过原生 NSPasteboard 写入系统剪贴板，浏览器预览使用浏览器剪贴板权限。没有实现 `.xlsx` 文件导入导出、公式计算或合并单元格。矩形拖选已在 0.17.2 实现，见 [区域操作](TABLE-RANGE.md)。

## 保护与上限

只替换受影响的行内区域/单元格；保留其他单元格原始空格、对齐语法、表格外文本以及原有 BOM/行尾。新增行使用文稿既有默认行尾。文稿变化、只读或候选输入时拒绝陈旧操作。

一次粘贴最多 1 MB、5,000 行、100 列、50,000 个单元格，单元格 20,000 字符。原有即时预览前 100 行的提示保持，导出仍处理完整文稿。原生复制文本上限 1 MB。

引用块里的 `>` 不作为单元格，单元格源码位置按实际容器前缀计算；追加行保留引用或列表缩进，行列工具也保留容器。后续补查发现的列错位和错误编辑目标已修复。

检查：7 项模型测试、8 项浏览器交互；原生 WebKit 矩阵粘贴/扩展/字节一致撤销；原生私有剪贴板验证中文与引用 TSV、候选保护、超限保护。测试没有覆盖用户的系统剪贴板，也未将程序化文本互通称为已人工操作每个版本的 Excel/Numbers。
