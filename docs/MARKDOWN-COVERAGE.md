# Markdown 解析与覆盖范围 · 0.17.1

2026-10-26。基线为 CommonMark、GFM，加上本项目已有的脚注、YAML Front Matter、公式、Mermaid 和图片属性。Markdown 存在多种方言，不能把所有第三方插件语法都宣称为已支持。

## 本轮修复

1. 即时行内排版从正则切换到语法树。支持加粗中的行内代码、三重强调、删除线中的代码、多反引号代码跨度、跨行强调；转义、代码、表格和图片源码不再被错误作为普通行内格式识别。
2. 无序列表的 `-`、`+`、`*` 在非活动行绘制为项目符号；活动行显示原始标记。保留源字符与宽度，避免用替换 HTML 重建正文或影响光标。编号列表保留编号。Setext 标题也有标题样式。
3. 补齐任务列表在独立 HTML/PDF 中的勾选状态，输出为无脚本的静态可访问标记。裸 URL 在正文和表格中有链接识别。
4. 加强代码词法分类。关键字、字符串、类型、函数、属性、数字和注释按主题使用语义配色。前六套主题原先关键字/字符串/数字同色，现在分开；修复 Ursine Dark 的低对比函数颜色，校正内置主题代码文字对比度。全部内置主题五类代码文字与代码底色的对比度达到 4.5:1；自定义主题保持用户设置。
5. 选择语言会更改实际围栏语言和解析器，不只是修改按钮。语言是识别规则，同一种语义在不同语言中使用同一主题颜色，不为每种语言硬套不同配色。
6. HTML 导出补齐标题目标 ID，复用编辑器锚点算法；支持中文、带格式标题和重复标题。`Same`、`Same`、`Same-1` 不再发生 ID 冲突。原始 HTML 内的标题不会抢占 Markdown 标题 ID。
7. 补查引用/列表中的表格，修复容器标记被误当作单元格、列错位及错误编辑目标；行列操作和粘贴保留容器。嵌套代码块改从语法位置识别，不依赖整行必须从反引号开始。链接也移除旧的行内正则着色，由真实链接语法和原位编辑组件处理，避免转义或嵌套写法误匹配。

## 覆盖清单

| 内容 | 即时编辑 | HTML / PDF |
| --- | --- | --- |
| ATX / Setext 标题 | 标题样式、源码标记可编辑 | 标准标题；Markdown 标题有共享锚点 |
| 无序/编号/嵌套列表、引用 | 标记与层级源文保留，项目符号绘制 | 标准列表/引用结构 |
| 任务列表 | 可勾选、可撤销 | 带完成状态的静态勾选标记 |
| 加粗、斜体、删除线及嵌套 | 语法树排版；活动行显示原始分隔符 | 共享 Markdown 解析 |
| 单/多反引号行内代码 | 等宽、底色，不解析代码内的格式 | 标准 code 文本 |
| 反斜杠转义、不完整标记、实体 | 保留可编辑源文，不误吞字符 | 按标准解析/解码 |
| 围栏/缩进代码 | 等宽；围栏可搜索选择语言 | 同语言语法高亮；未识别语言保持纯文本 |
| 行内/引用/自动链接 | 原位编辑与导航；裸 URL 可识别 | 安全链接；标题锚点可跳转 |
| 图片、引用图片及尺寸/对齐 | 原有图片组件与资源保护 | 内嵌授权可读取的图片 |
| GFM 表格及单元格行内格式 | 可视化编辑，前 100 行预览提示 | 完整表格与分页 |
| 横线、硬换行、软换行 | 源文本行结构保留 | 标准横线和换行规则 |
| 脚注、Front Matter、数学、Mermaid | 沿用现有组件及候选保护 | 共用规则和主题，已回归 |
| HTML | 安全子集，原文保留 | 清除脚本、事件与危险资源 |

即时模式是保留源文的编辑排版，编辑中的标记和换行仍可见，不是把整篇 HTML 反向写回 Markdown。它与导出的页面布局并非逐像素相同。

## 明确边界

- 不声称支持任意 Obsidian/其他编辑器插件语法。Wiki 双链、嵌入、Dataview、任意自定义容器等尚未作为功能实现；保持原始文本。
- 上下标、emoji 短码、文本高亮、定义列表等非 CommonMark/GFM 标准语法未在此轮补为完整渲染功能。
- GitHub NOTE/TIP/IMPORTANT/WARNING/CAUTION 提示块已在 0.17.1 支持，限顶层引用、独立标记行；未知类型与嵌套写法保留普通引用。详见 [提示块](CALLOUTS.md)。
- HTML 仅为安全子集；通过全部标准解析样例不等于允许执行样例中的脚本。
- 以 `---` 开始且有关闭分隔符的文档，默认优先识别为 Front Matter；标准测试配置单独关闭此扩展。原始字节不因此改变。
- 仍按既有规则限制图表规模、远程图片授权和超大表格即时渲染。未支持的内容不静默删除。

## 验证与来源

- `node scripts/test-commonmark.mjs`：CommonMark 0.31.2 官方 652 个样例全部通过。仅关闭 Front Matter 和裸链接扩展，规范化等价的 HTML5 空元素/XHTML 斜杠、空引用序列化；测试不关闭代码跨度或强调规则。
- 官方样例保存在忽略的 `.build/commonmark-0.31.2.json`，不作为应用素材或项目源码重新分发。结果报告包含来源与 SHA-256。首次运行前下载：`curl -fsSL https://spec.commonmark.org/0.31.2/spec.json -o .build/commonmark-0.31.2.json`。
- `tests/markdown-coverage-browser.mjs`：嵌套排版、列表、Setext、12 种语言、实际语言切换/撤销、组合输入、原样保存和导出。
- `tests/heading-anchors-browser.mjs`：中文/重复/带格式标题、HTML 标题隔离、导出后点击实际滚动。
- `scripts/test-markdown-pdf.sh`：实际语法页面、明暗主题与 120 行长表；输出 PNG 已查看。
- 标准依据：[CommonMark 0.31.2](https://spec.commonmark.org/0.31.2/) 与 [GFM](https://github.github.com/gfm/)。
