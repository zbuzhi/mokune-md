# 编辑与预览

- `⌘/` 在即时排版与源码模式之间切换，保留选区和当前标签的撤销历史。光标进入可编辑语法区域时显示 Markdown 标记。
- 表格单击单元格直接编辑，Tab/⇧Tab 在格间移动；右键提供行列插入、删除及对齐。区域选择、复制和 TSV 粘贴见 [表格互通](TABLE-TRANSFER.md) 与 [区域操作](TABLE-RANGE.md)。
- 图片默认直接显示；悬停左上角提供对齐操作，边缘和四角可拖动尺寸。右键修改替代文字、标题与来源；点击打开缩放查看器。详见 [图片与附件](RESOURCES.md)。
- 大纲占独立页边区域，悬停展开，可固定或设置左右位置；文件列表按目录树显示。见 [导航](NAVIGATION.md)。
- 独立标签保留各自源文、选区和撤销；重启恢复不等于跨进程保留撤销栈。见 [会话与链接](SESSION-AND-LINKS.md)。

中文组合输入期间不会执行会打断候选的格式操作、预览重建或更新退出。表格和其他编辑弹层打开时，也会保护当前编辑。更多格式快捷键见 [快捷键](SHORTCUTS.md)，语法边界见 [Markdown 支持](MARKDOWN-COVERAGE.md)。
