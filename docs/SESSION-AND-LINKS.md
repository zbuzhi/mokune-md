# 完整会话与移动链接维护 · 0.14.0

## 会话恢复

默认启动恢复全部标签、标签顺序、当前文稿，以及各文稿的光标／选区方向、滚动位置、源码／阅读模式。后台标签按首次激活加载，避免启动时依次渲染所有文稿。新建的空白文稿也保留。

“编辑设置 → 启动时恢复上次会话”控制自动恢复；关闭后仍保留已有未保存草稿的恢复入口。“记住文稿位置”控制是否应用持久化光标和滚动位置。

会话存放在 `~/Library/Application Support/Mokune/session.json`，采用原子写入，源文及磁盘基线保存为完整 UTF-8 字节。草稿沿用 `recovery.json`，恢复时合并，不静默丢弃孤立草稿。中文候选期间不采集阅读位置或草稿，提交后再调度；退出前同步当前文稿。

正常退出仍逐份询问未保存内容，支持保存、取消和不保存。完成处理不再移除标签，保留退出前原本选中的文稿；主动关闭某个标签则从会话中移除。“不保存”不会在下次启动重新恢复被主动丢弃的文字。没有路径的未命名文稿会保留空标签。

已保存文稿重启时读取磁盘最新内容；未保存文稿保留草稿及原磁盘基线，发现外部修改时进入原有冲突保护。原路径缺失或无法读取时，恢复为无路径的未保存副本，避免向丢失位置静默写入。

当前会话切换标签仍保留独立撤销栈；重启后从新撤销栈开始，不序列化旧进程的 CodeMirror 历史。崩溃恢复仍有短延迟窗口，不承诺保存进程被强制结束前尚未完成持久化的最新输入。

## 文件移动后的链接

通过应用文件树重命名或拖拽移动文件／文件夹时，先扫描所选工作区，再一起维护：

- 其他文稿指向移动目标的相对链接。
- 被移动文稿自身的相对文稿与图片路径。
- 行内链接、图片、引用式链接定义和常见 HTML `a` / `img` / `source` / `video` / `audio` 的 `href`、`src`、`poster`。
- 路径中的空格、中文、括号及原查询参数／标题锚点。

仅改动目标路径范围，保留标签文字、标题、BOM、行尾和其他源文。整目录移动而相互关系未变化的内部引用保留原写法。远程 URL、纯锚点、代码示例、公式、Front Matter 及 HTML 注释保持原样；不处理 `srcset`、CSS URL、YAML 自定义资源字段和工作区之外的引用。Finder 等外部程序发起的移动尚不自动维护引用。

已打开文稿的链接更新是一笔独立可撤销事务，保留此前未保存内容、选区及各标签撤销历史，之后按原自动保存设置处理。重启后尚未访问的后台标签使用更新后的原生草稿；候选、图片操作和单元格编辑期间不强行替换编辑器。

未打开文稿更新前保留本地版本快照，再核对磁盘基线并原子写入。扫描期间发生编辑、外部修改或工作区文件增减时拒绝过期移动。多文件写入中途失败时尝试回退已写入的内容与移动；若外部程序同时修改导致无法安全回退，明确提示检查文件树，不覆盖外部内容。

完整扫描上限为工作区 10,000 份文稿、40 MB 文本总量，单文件沿用 20 MB 上限。超过上限时拒绝移动并提示缩小工作区，不静默跳过未扫描文稿。扫描在后台进行。

为支持移动后 `../assets/...` 等路径，预览与导出允许读取所选工作区内的图片；未选择相应工作区时仍限定文稿所在目录。路径会经过真实路径及符号链接检查，不能借此越过工作区边界。
