# 冲突逐段处理 · 0.16.0

## 使用

发生外部修改后，点击通知中的“比较版本”，或从命令面板选择“比较磁盘版本”。比较当前编辑与磁盘最新内容，逐段选择“保留当前编辑”或“使用磁盘内容”，也可使用“全部保留当前 / 全部使用磁盘”。默认不替用户作出选择。

全部差异段选择完成后，点击“预览合并结果”。预览显示完整的合并后 Markdown 源码，可返回调整选择。点击“应用合并”才更新编辑器；预览、选择及取消本身不修改正文或磁盘。

合并作为一次独立事务应用，⌘Z 恢复合并前的完整草稿及选区，⌘⇧Z 重做；更早的编辑历史继续独立保留。未涉及区域的光标通过局部变化映射。修改保留原始 BOM、每个来源片段的行尾与尾随空格，不经过 Markdown 格式化或 HTML 反向序列化。

BOM 单独作为编码标记差异展示。仅行尾或空白不同的段落显示 CRLF / LF / CR、空格和制表符标记，避免两侧看起来完全一样；这些标记只用于比较界面。格式变化即使不改变规范化正文，也会更新草稿、版本号、状态栏，并可撤销。

两侧内容完全一致但磁盘保存基线已经变化时，也可预览一致内容并确认磁盘版本，避免反复报冲突。

## 保存与并发保护

应用合并后保持“尚未保存”，暂停自动保存。确认内容后按 ⌘S 手动保存；关闭文稿或退出时仍有未保存保护。切换标签保留各自正文、冲突状态、撤销、选区及滚动位置。

应用前核对当前文稿身份、修订号、源文、原保存基线，以及磁盘的完整字节。两份输入先分别留入原有本地版本历史，再次检查磁盘后才允许编辑器应用。版本历史仍受原来的保留上限约束。

应用过程中不修改原磁盘文件，也不提前替换原保存基线。合并授权随编辑器撤销／重做状态保留，保存时仅对当前标签使用已确认的磁盘快照，并再次经过原有原子写入基线检查。若磁盘在预览后或应用后又变化，拒绝覆盖并保留草稿；可重新比较。

撤销合并会撤销对应的保存授权。合并后继续输入仍保留原有中文输入与撤销规则。应用合并后重启，会恢复未保存源文；若原磁盘基线已经变化，需要重新比较确认后保存，不沿用旧进程的授权。

即使选择“全部保留当前”且文字碰巧等于此前已保存内容，也会以冲突草稿保护，而不是误判为无修改并丢弃。延迟到达的保存回执只清除相应标签、相应修订的已解决状态，不清除更晚的合并／撤销状态。

## 面板与输入

面板使用当前主题，差异选择和完整预览在同一弹层内切换。面板期间不允许正文编辑、切换文稿、应用其他格式操作或导出；关闭后恢复原焦点。面板中的撤销快捷键不会消费正文撤销历史。

中文候选组合输入期间不打开合并面板；面板组合事件期间不应用、切换选择或关闭。异步读取期间发生输入或修订变化，会要求重新比较，而不覆盖新内容。

只读文稿继续使用原来的只读比较。逐段处理目前支持两侧 UTF-8 总计 2 MB、总计 24,000 行以内；超过范围保留原有只读比较和另存入口。计算预算过大或差异段超过 300 个时，以完整的大区段处理并明确标识，不省略源文，也不构造大量差异控件。
